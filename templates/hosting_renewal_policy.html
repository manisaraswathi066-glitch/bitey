1. Website with Hosting Package Scope (₹7,000)

For clients selecting our turnkey "Website with Hosting" package starting at ₹7,000:

  • Hosting Duration: Includes one (1) full year of shared cloud web hosting from the date of launch.
  • Domain Registration: Includes registration assistance for one standard domain name (.com or .in) for the first year. Premium or copyrighted domains are subject to registrar surcharges.
  • SSL Certificate: Automated Let's Encrypt SSL certificates are provisioned and renewed free of charge for HTTPS security.

2. Annual Renewal Schedules and Costs

To keep the website live on public servers beyond the initial 12-month period, hosting and domain registrations must be renewed annually:

  • Estimated ongoing renewal is ₹2,500 per year, covering server storage, domain renewal, SSL maintenance, and routine security patching.
  • Bitetech Technologies issues renewal reminders 30 days and 7 days prior to expiry via email and WhatsApp.

3. Code Ownership and Migration Rights

Clients retain 100% ownership of their website source code and database assets. If a client prefers to transfer their website to another hosting provider at the end of the term, Bitetech Technologies will provide a complete, compressed backup of the files and SQL database at no penalty fee.

4. Third-Party Outages and Backups

We maintain weekly automated offsite backups. While our upstream cloud infrastructure maintains a 99.9% uptime objective, Bitetech Technologies is not liable for scheduled upstream data center maintenance or force majeure network outages.
